# Digital Wallet & Money Transfer System

A backend engineering project for building a secure digital wallet
and money transfer system using Node.js, Express.js, TypeScript,
and PostgreSQL.

## Goals

- Secure user authentication
- Wallet management
- Deposits and withdrawals
- Atomic money transfers
- Transaction integrity
- Idempotent APIs
- Concurrency control
- Automated testing
- Docker-based development

## Tech Stack

- Node.js
- Express.js
- TypeScript
- PostgreSQL
- Redis
- Docker
- Vitest

## Development

Install dependencies:

npm install

Start the development server:

npm run dev

Build the project:

npm run build

Run type checks:

npm run typecheck
